# Personalized Zen Garden: A Virtual Retreat for Mindfulness

This repository contains the implementation and report for the project:

**"Personalized Zen Garden: A Virtual Retreat for Mindfulness"**

---

Overview

The Personalized Zen Garden is an immersive AR/VR-based system designed to promote mindfulness, relaxation, and mental well-being.

It provides users with a **customizable virtual environment** that adapts to their emotional state using AI-driven personalization and interactive 3D elements.

As described in the project report , the system combines:

* AI-based mood adaptation
* Virtual Reality (VR) immersion
* Augmented Reality (AR) interaction

to create a dynamic and engaging meditation experience.

---

Key Features

 AI-driven personalized Zen Garden
 Emotion-based environment adaptation
 VR immersive meditation experience
 AR-based real-world interaction
 Ambient sound and guided meditation
 Gesture-based interaction

---

##How It Works

According to the system workflow (Section 3 in the report) :

1. User creates a profile
2. AI analyzes preferences and mood
3. Zen garden is generated dynamically
4. User interacts via AR/VR
5. System adapts based on feedback

---

Results

* 89% users reported improved relaxation
* 92% found AR/VR interaction engaging
* AI personalization improved user experience significantly

The system successfully demonstrates the effectiveness of immersive environments for mindfulness.
